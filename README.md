# TaikoDatatableTabulator

**Archived.** This tool was replaced by [TaikoDataConverter](https://github.com/S-Sebb/TaikoDataConverter) (`tdc`). This repo is read-only and gets no more updates.

| Replaced by | Does |
|---|---|
| `tdc datatable musicinfo` | Writes `musicinfo` as CSV, one row per song (was `make_csv.bat`). |

Install and usage: see the [TaikoDataConverter README](https://github.com/S-Sebb/TaikoDataConverter#readme). tdc reads its keys from a `.env` file instead of the code.
